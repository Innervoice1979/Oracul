# InnerVoice ESP Oracle — Прошивка

## Требования

### Плата
- ESP32-C3 SuperMini

### Компоненты
- TFT ST7789 1.54" (240×240, SPI)
- MPU6050 (I2C акселерометр/гироскоп)
- TTP223 (емкостная кнопка)

### Библиотеки Arduino
Установите через Library Manager:
1. **Adafruit GFX Library**
2. **Adafruit ST7789 Library**
3. **U8g2 for Adafruit GFX**

### Настройки платы в Arduino IDE
- Board: **ESP32C3 Dev Module**
- USB CDC On Boot: **Enabled**
- CPU Frequency: **160MHz**
- Flash Mode: **QIO**
- Flash Size: **4MB**

## Подключение

### TFT дисплей ST7789 (SPI)
Модуль имеет пины: GND VCC SCL SDA RST DC CS BL

| Пин модуля | Пин ESP32 | Назначение |
|------------|-----------|------------|
| GND        | GND       | Земля |
| VCC        | 3.3V      | Питание |
| SCL        | GPIO5     | SPI Clock (НЕ I2C!) |
| SDA        | GPIO6     | SPI Data/MOSI (НЕ I2C!) |
| RST        | GPIO3     | Reset |
| DC         | GPIO7     | Data/Command |
| CS         | GPIO10    | Chip Select |
| BL         | GPIO21    | Backlight (PWM) |

### MPU6050 акселерометр (I2C)
Модуль имеет пины: SCL SDA XDA XCL ADO INT

| Пин модуля | Пин ESP32 | Назначение |
|------------|-----------|------------|
| SCL        | GPIO0     | I2C Clock |
| SDA        | GPIO1     | I2C Data |
| XDA        | —         | Не подключать (auxiliary) |
| XCL        | —         | Не подключать (auxiliary) |
| ADO        | GND       | Адрес 0x68 (если VCC → 0x69) |
| INT        | GPIO4     | Interrupt (wake-up) |

### Кнопка TTP223
| Пин модуля | Пин ESP32 | Назначение |
|------------|-----------|------------|
| SIG        | GPIO20    | Signal (Active HIGH) |
| VCC        | 3.3V      | Питание |
| GND        | GND       | Земля |

### Вибромотор (через NPN транзистор)
| Компонент | Подключение |
|-----------|-------------|
| Motor+    | 3.3V |
| Motor-    | Collector NPN (BC547/2N2222) |
| Base      | GPIO2 через R 1kΩ |
| Emitter   | GND |

## Wi-Fi (опционально)

Откройте файл и измените:
```cpp
const char* WIFI_SSID = "ваша_сеть";
const char* WIFI_PASS = "ваш_пароль";
```

## Режимы

1. **Оракул** — тряска или долгое нажатие → ответ
2. **Часы** — время, дата, NTP
3. **Игры** — Змейка (наклон), Реакция
4. **Сеть** — Wi-Fi статус, mDNS
5. **Робот** — Jarvis HTTP мост
6. **Настройки** — диагностика

## Управление

- **Короткое** — следующий режим
- **Долгое (700ms)** — действие режима
- **Двойное (300ms)** — яркость

## Пробуждение

Устройство уходит в deep sleep через 25 сек бездействия.
Пробуждается от тряски (MPU6050 INT → GPIO4).

## Вибромотор

Простой DC вибромотор с маховиком (эксцентриком). Подключается через NPN транзистор (BC547/2N2222/S8050) или MOSFET модуль.

### Подключение
```
GPIO2 → R 1kΩ → база транзистора
Мотор: коллектор → 3.3V, эмиттер → GND
```

### Тактильные отклики
- **Тик (30мс)** — нажатие кнопки, разгон в AUTO
- **Пульс (80+50+80мс)** — ответ оракула, поедание в змейке, торможение
- **Длинный (250мс)** — Game Over, пробуждение, резкий манёвр, "ЖМИ!" в реакции
- **Тряска** — неровная дорога в AUTO режиме
- **Думает (пульсация 1 сек)** — оракул генерирует ответ

### Отключение
Если вибромотор не подключен, в коде установите:
```cpp
#define VIBR_ENABLED 0
```
